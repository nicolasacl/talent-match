# TalentoMatch

## Título del Proyecto y Descripción General
**TalentoMatch** es una plataforma inteligente diseñada para resolver la problemática del reclutamiento ineficiente y la selección manual de personal en el sector tecnológico. La aplicación automatiza el cruce de datos entre las habilidades técnicas de los candidatos y los requerimientos específicos de las vacantes, generando un porcentaje de compatibilidad preciso y optimizando el tiempo de los reclutadores.

## Tecnologías y Librerías Utilizadas
* **Lenguaje:** Python 3.x (Modularización avanzada y buenas prácticas de desarrollo)[cite: 4]
* **Estructuras de Datos:** Manejo de JSON y manipulación de colecciones (Sets y Listas)[cite: 4]
* **Control de Versiones:** Git y GitHub[cite: 4]
* **Entorno de Desarrollo:** Visual Studio Code[cite: 4]

## Estructura del Repositorio
* `main.py`: Archivo central que orquesta la lógica de negocio, filtros de compatibilidad y control de excepciones.
* `data.json`: Base de datos local simulada con el registro de perfiles y habilidades de los candidatos.
* `README.md`: Documentación oficial y técnica del proyecto.
